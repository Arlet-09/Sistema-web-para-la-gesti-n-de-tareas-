HU01 – Registro de tareas

Como usuario, quiero registrar nuevas tareas para organizar mis actividades.

Criterios de aceptación:
- Ingresar el nombre de la tarea.
- Agregar una descripción.
- Seleccionar una prioridad.
- Guardar la tarea.
- Mostrar un mensaje de confirmación.

HU02 – Consulta de tareas

Como usuario, quiero visualizar todas las tareas registradas para conocer mis actividades.

Criterios de aceptación:
- Mostrar todas las tareas.
- Visualizar nombre y descripción.
- Mostrar estado y prioridad.
- Actualizar el listado cuando se registre una tarea.

HU03 – Edición de tareas

Como usuario, quiero modificar una tarea para mantener actualizada su información.

Criterios de aceptación:
- Seleccionar una tarea existente.
- Modificar nombre y descripción.
- Modificar prioridad.
- Guardar los cambios.

HU04 – Eliminación de tareas

Como usuario, quiero eliminar tareas existentes para mantener organizado mi listado.

Criterios de aceptación:
- Seleccionar una tarea.
- Solicitar confirmación.
- Eliminar la tarea.
- Actualizar el listado.

HU05 – Cambio de estado

Como usuario, quiero cambiar el estado de una tarea para conocer su progreso.

Criterios de aceptación:
- Seleccionar pendiente.
- Seleccionar en proceso.
- Seleccionar terminada.
- Guardar el cambio.
- Mostrar el estado actualizado.

HU06 – Asignación de prioridad

Como usuario, quiero asignar una prioridad a cada tarea para identificar las actividades que requieren mayor atención.

Criterios de aceptación:
- Seleccionar prioridad alta.
- Seleccionar prioridad media.
- Seleccionar prioridad baja.
- Guardar la prioridad.
- Mostrarla en el listado.
